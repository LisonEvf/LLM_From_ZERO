# 从零构建大语言模型

Welcome to LLM_From_ZERO!

这是一个以**叙事方式**展开的大语言模型技术教程。我们从Tokenizer的设计智慧讲起，一路蜿蜒至Attention革命、GPT的Scaling、MoE稀疏化、量化的压缩，最终抵达现代LLM的完整技术栈。

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行第一个notebook
jupyter notebook notebooks/01_BPE_Tokenizer.ipynb
```

## 项目结构

```
LLM_From_ZERO/
```
